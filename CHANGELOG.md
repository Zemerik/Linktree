## [2.0.1] - 2025-12-30

### 🎨 UI/UX Overhaul

This release introduces a complete visual redesign of the linktree, transforming it into a modern, polished experience with cutting-edge design trends.

#### Visual Design
- **Animated Gradient Background**: Implemented a dynamic, color-shifting gradient background that smoothly transitions between purple, pink, blue, and cyan tones
- **Glassmorphism Effects**: Added frosted glass (glassmorphism) styling to all interactive elements, creating depth and a modern aesthetic
- **Animated Particles**: Introduced subtle floating particles in the background for added visual interest
- **Profile Image Enhancements**: Profile picture now features a floating animation with a rotating gradient glow effect

#### Typography & Layout
- **Modern Font**: Integrated Inter font family for improved readability and contemporary feel
- **Enhanced Typography Hierarchy**: Improved text sizing, spacing, and visual hierarchy throughout the page
- **Better Spacing**: Refined spacing and padding for improved visual balance and readability

#### Interactions & Animations
- **Smooth Hover Effects**: Enhanced button hover states with ripple effects and smooth lift animations
- **Staggered Fade-in Animations**: Links now fade in sequentially for a polished loading experience
- **Social Icon Interactions**: Social media icons feature glassmorphism containers with smooth hover effects and scaling animations
- **Improved Transitions**: All animations use smooth cubic-bezier timing functions for professional feel

#### Technical Improvements
- **Responsive Design**: Ensured optimal viewing experience across all device sizes
- **Accessibility**: Added proper `aria-label` attributes and semantic HTML improvements
- **Performance**: Optimized animations and CSS for smooth performance
- **Code Quality**: Improved code organization and maintainability

#### Bug Fixes
- Fixed inconsistent icon path formatting (standardized to use leading slashes)
- Improved meta tags for better SEO and social sharing
